Atomic Heart is a first-person shooter in an alternative soviet setting developed by Mundfish studio.

As a technical designer I was in charge of prototyping, developing, iterating, polishing, bug fixing, and optimization of gameplay systems, player abilities, and interactive content on levels.

Technologies I used on a daily basis:

  • Unreal Engine 4 editor and tools
  • Blueprints
  • C++ programming language.

Table of contents:

    Please note: I did not create art, animations, UI, VFX, final texts, sound, engine-level programming, or low-level systems. These aspects were managed by other team members, with whom I closely collaborated during the development of each feature below.

    Ecosystem

    A system that allows the player to disable all cameras and robots in the current region for some time. Disabled robots will re-activate upon taking damage.

    Zipline

    An interactive rope that allows the player to slide from start to finish.

    Jumping out of the car

    The player's ability to jump out of the car while it's in motion.

    New Game +

    A "New Game +" mode where the player is allowed to replay the game's story while retaining abilities, resources, and upgrades accumulated in the first playthrough. This mode introduces tougher versions of enemies with new abilities.
